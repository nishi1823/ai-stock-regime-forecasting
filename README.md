# AI Stock Market Regime Detection & Forecasting

A machine-learning research platform for detecting market regimes, forecasting short-term stock returns, and evaluating systematic trading strategies.

## Overview

This project investigates whether machine-learning-based market regime detection and return forecasting can support systematic trading decisions.

The system combines:

- Real SPY market data
- Financial feature engineering
- K-Means market regime detection
- Random Forest return forecasting
- Trading signal generation
- Strategy backtesting
- Risk analysis
- Interactive Streamlit dashboard
